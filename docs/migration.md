## 待关闭的问题

- UI 布局、分组标题、菜单、字体栅格、焦点及 DPI 仍有差异；未完成鼠标/键盘全流程验收。
- Chromium日期/颜色编辑弹层正在按原版实际截图实现；大段Base64同步解码仍需移入后台。
- Pin独立截图路径已修复；文字/图片/效果面板均已实际采集。仍有字体、SVG抗锯齿和玻璃效果差异，不能据此认定全部视觉一致。
- Everything 实机查询和 Windows Search 非空结果未验证；后者在本机触发系统查询超时。
- 目标仍在进行中；本阶段保存可编译、已回归的独立提交，继续关闭上述差异。
