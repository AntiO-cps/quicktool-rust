# 搜索与输入布局对照（alpha.37）

## 已修复

| 问题 | 原因 | 修改 |
| --- | --- | --- |
| 输入后反复抖动 | 异步应用图标使相同行高从62变66，四个图标分批到达反复改变目标高度；选中行每帧自动滚动 | 图标使用固定34px槽；只在选择变化后滚动；布局测量不受动画中的裁切高度限制 |
